# Co-op free roaming: a key door a teammate opened in its own copy of the
# room (another world instance) stays open when the worlds merge, even when
# the world that stays is the one that had the room loaded with the door
# still locked. The key it took isn't lost.
load 2
run 30
# Skull Woods: the big chest room; its south wall has a small key door
# (door slot 2) down to the room below.
enter 58
run 200

run 20
poke f36f 01
run 2

pos 2 4280 2944

run 20

expect_apart 1 2
