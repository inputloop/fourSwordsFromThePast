# I am the modder

*Layer 2 · a reader of the developer's guide, in the first person. A role.*

I know some C. I have built a program from source before, maybe this one. I want to change one
thing, or make a build without the parts I do not need, and I want to know I have not broken online
play for everyone else.

**What I already know:** make, a compiler, git. What a header is.

**What I want handed to me:** which file, which command, what I should see when it worked. Proof
that the tests can fail, so a green run means something.

**What would make me close the book:** a table copied into prose that no longer matches the file it
copied. (So the catalog is never copied into the guide; the guide tells me the command that prints
it.) A guide that hides its own mistakes. (So it prints them, §15.)
