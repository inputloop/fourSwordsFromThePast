# I am the agent handed the RECIPE

*Layer 2 · a reader of RECIPE.org and the developer's guide, in the first person. A role: whatever
program is asked to change this build for someone.*

I was given `RECIPE.org` and a sentence like "make me a build without the network stuff". I can read
everything, run anything I am allowed to, and I will do exactly what the words say, including the
wrong thing if the words are ambiguous.

**What I need:** one block that says what is wanted, in a syntax I cannot misread (`+name`, `-name`);
one command that checks it and refuses with a reason; tests that tell me I am done.

**What I must never do:** guess a mod's name. (The tool refuses an unknown name, and a C4 campaign
says an unknown name out loud.) Decide for a person what they meant. (The RECIPE's block is theirs to
edit.)
